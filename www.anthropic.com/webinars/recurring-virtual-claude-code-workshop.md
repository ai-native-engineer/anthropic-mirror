# Virtual Claude Code Workshop

This Claude Code workshop, presented with Tenex, is a 1.5 hour product experience for engineers who ship in codebases they did not write — platform, product, infrastructure, and the teams that own what runs in production.The focus is the product, the people who build it, and the work you do every sprint.

## What you’ll learn

* **See Claude Code on a real codebase, not a to-do app.** A fintech merchant console you have never seen, a real ticket, and a change planned before a line gets written — shown as one continuous workday, not a feature tour.
* ​**Take a ticket to a pull request in 90 minutes.** Hands-on from the first minute: clone, trace the code, build the feature, open the PR. Anthropic and Tenex engineers on the call to unblock you.
* ​**Leave with tooling, not a pile of notes.** You walk out with a [CLAUDE.md](https://claude.md/?utm_source=luma) and a skill you wrote yourself, checked into git — ready to drop into your own repo Monday morning.

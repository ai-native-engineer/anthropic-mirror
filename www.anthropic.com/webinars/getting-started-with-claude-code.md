# Getting started with Claude Code

Get up and running on Claude Code through hands-on guidance. We'll guide you through writing your first CLAUDE.md and running a real task in your own repo while ensuring you understand best practices in getting the most value from Claude while keeping costs under control. This session is best for developers. Have Claude Code downloaded so you can dive right in!

## What you’ll learn

* How to go from a cold install of Claude Code to a real fix in your own repo
* How to teach Claude your codebase with a CLAUDE.md and skills
* Best practices for getting the most value from Claude Code while keeping costs under control
* How to scale from a single agent to a fleet using MCP connectors

# Ship Code Faster with Claude Code on Vertex AI

Explore how to build and access Claude Code on Vertex AI to accelerate your development workflows. In this technical webinar, we'll walk through Claude Code's capabilities and how to set it up on Vertex AI. Through live demonstrations, you'll see how Claude Code handles real coding tasks end to end so you can start building with confidence on Vertex AI. We’ll also answer some of the top developer community questions for building with Claude on Vertex AI.

*Pre-recorded event: This is a rebroadcast of our April 2 session. Anthropic team members will be in the chat live to answer your questions.*

## What you’ll learn

* Understand Claude Code's core capabilities and how they map to real development workflows
* Get clarity on feature availability between Claude Code and Vertex AI, so you can make architecture decisions without ambiguity
* Get up and running with Claude Code on Vertex AI, including how OAuth and API key authentication methods differ, how environment variables behave across sessions, and how to avoid silent auth conflicts
* Apply best practices for building with Claude Code on Google Cloud

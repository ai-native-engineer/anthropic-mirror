# Claude for Financial Services: Putting agents to work

A practitioner’s session on Claude capabilities specifically for financial services. We’ll show Claude taking on the analyst- and operations-grade work that fills your day and walk through how to deploy an agent against common workflows, wired into the data and tools you already use.

## Featuring

No items found.

## What you’ll learn

* A working demo of Claude agents on representative financial services workflows — deal-side and operations — run end to end on the documents and data those workflows actually use
* How to scope an agent to a specific role on your team: choosing the first workflow, connecting the right tools and data, and setting where it hands work back to you
* What it takes to stand this up in a financial services environment — access, controls, oversight, and the deployment patterns we’ve seen get a first agent into daily use fast

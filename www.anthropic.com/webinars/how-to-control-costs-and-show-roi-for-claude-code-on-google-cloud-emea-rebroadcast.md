# How to control costs and show ROI for Claude Code on Google Cloud

Teams running Claude Code at scale eventually get the same two questions. What is this costing us, and are the results worth the investment? This technical webinar shows you how to answer both. We'll configure the Claude apps gateway on Google Cloud to govern spend and access, then show you how to turn the data it produces into a business case that holds up under scrutiny.

Pre-recorded event: This is a rebroadcast of our 1 September session. Anthropic team members will be in the chat live to answer your questions.

## What you’ll learn

* Showing the return on your Claude Code on Google Cloud investment, connecting usage data to productivity signals like commits, pull requests, and cost per commit.
* Measuring AI adoption across your organization, including active developers, session counts, and how teams are using skills and plugins.
* Best practices for controlling AI costs, including spend caps by user, team, and organization, and model access rules enforced centrally.
* Keeping cost and access data accurate at the infrastructure level, so the numbers you're reporting reflect what's happening across every developer's session.

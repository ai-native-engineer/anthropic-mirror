# Claude Code in Financial Services: From Analyzing Data to Modernizing Legacy Systems

Join Anthropic's technical leaders and our internal finance team for an exclusive deep dive into how Claude Code transforms financial services development workflows.

See live demonstrations of real-world applications including how to analyze massive trading datasets, create forecasts, and migrate legacy COBOL systems to the cloud.

Learn proven best practices from major banks and get actionable guidance on achieving faster migrations and reducing manual code review overhead.

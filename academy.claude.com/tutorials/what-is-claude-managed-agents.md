# What is Claude Managed Agents?

Claude Managed Agents is a suite of APIs for building production-ready agents. You define the tools, environments, and success criteria.

Claude works until the job is done. This video demos a Kanban board that fires agent sessions on ticket drag, a weekly SaaS pricing research agent, with persistent memory, and a multi-agent incident response system with human-in-the-loop approval. Outcomes, multi-agent orchestration, and memory are part of the Claude Managed Agents beta, enabled by default for all API accounts.

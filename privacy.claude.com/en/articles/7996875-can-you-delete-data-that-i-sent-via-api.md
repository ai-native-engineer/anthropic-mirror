# Can you delete data that I sent via API?

*This article is about our commercial products such as Claude for Work and the Anthropic API. For our consumer products such as Claude Free, Pro, Max and when accounts from those plans use Claude Code, see* *[here](https://privacy.anthropic.com/en/articles/10067979-what-personal-data-is-collected-when-using-dictation-on-the-claude-mobile-apps).*

## Deleting and Renaming Individual Conversations

For paid API customers, we do not support ad hoc deletion. See [here](https://privacy.anthropic.com/en/articles/7996866-how-long-do-you-store-personal-data) for more information on our data retention practices. We do not use API data for training (unless you have an agreement with us that states otherwise).

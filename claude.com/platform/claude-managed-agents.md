## Frontier capabilities, built in

Memory

### Every session makes the next one better

Claude writes what it learns to memory, and later sessions read from it.

Multiagent orchestration

### A lead agent assigns work to specialists

Each specialist has its own model, prompts, and tools. They share a filesystem to collaborate in.

Outcomes

### Claude grades its own work, then fixes it

The grader scores each output and sends it back for revision until it meets your bar.

Vaults

### Credentials stay out of the sandbox

The vault adds your secrets at the network boundary, so the agent only handles a placeholder.

Scheduled deployments

### Agents run on a schedule you set

Runs at the times you set. Memory persists between runs.

Self-hosted sandboxes

### Agents’ tools can run in your environment

Tools run and execute on files in your infrastructure, using clients preconfigured to your specifications.

## FAQ

### What is Claude Managed Agents?

Claude Managed Agents is a suite of composable APIs for building and deploying cloud-hosted agents at scale. It pairs an Anthropic-managed harness with production infrastructure for state, memory, permissions, and scheduled execution.

### How is Claude Managed Agents different from the Agent SDK?

The Agent SDK runs locally on your own machines. Claude Managed Agents gives you the hosted infrastructure to run agents in the cloud, with sessions, sandboxes, and permissions managed for you.

### Where does the agent run, and can its tools run in our own cloud?

Each agent’s code runs in its own isolated sandbox on the Claude Platform.

If you need tools, files, and credentials to stay in your environment, self-hosted sandboxes keep them in your cloud.

### How are credentials and data protected?

Credentials are stored in a vault and added at the network boundary, so the agent and its code only ever see a placeholder. Instructions are kept outside the sandbox too, so nothing the agent runs can reach them.

You can delete sessions through the API and use your own encryption keys for stored data.

### How much control do I have over what the agent does?

For each tool, you choose whether it runs automatically, always waits for approval, or is checked first and then run, denied, or paused for a person to review. Tools from connected MCP servers ask for approval by default.

You can also limit networking with domain allowlists, so the sandbox, web search, and web fetch only reach the hosts you name.

### Is it available on cloud platforms?

Claude Managed Agents is currently available on Claude Platform on AWS.

### Is it HIPAA eligible?

No, Claude Managed Agents is not currently HIPAA eligible.

### How much does it cost?

Anthropic charges token rates plus $0.08 for each hour a session runs. There are no platform or seat fees, and it counts towards commits.

* Use case

Cursor is an AI coding platform used by teams to write, review, debug, and ship software. Agents work against your own codebase, documents, and tools and everything stays grounded in your data, documents, and knowledge.

What you can do:

• Context from your systems: Connect your repos, docs, and tools so agents plan and produce code from your real knowledge, not a guess.
• Full lifecycle: Write, review, debug, and ship in the same place, including automated review with BugBot.
• Team controls: Set model access, tool connections, and agent rules so the work matches how your engineering org already operates.
• Built for production teams: More than 50,000 businesses, including 67 percent of the Fortune 500, use SpaceXAI, writing over 150 million lines of enterprise code each day.

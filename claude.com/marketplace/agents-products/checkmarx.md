Checkmarx is an application security platform used by security and development teams to find, prioritize, and fix vulnerabilities before code ships, scanning trillions of lines of code each year. Claude powers the reasoning behind Checkmarx Fusion, a hybrid code security engine and behind Checkmarx Triage and Remediation Assist prioritization and fix agents.

## What you can do

* **Detection:** Checkmarx Fusion SAST combines deterministic scanning with Claude’s reasoning to discover the most comprehensive set of vulnerabilities that are exploitable.
* **Prioritization:** Triage Assist ranks every finding by real-world risk in your environment, so your team is working through a prioritized list of attackable vulnerabilities.
* **Remediation:** Remediation Assist turns a prioritized vulnerability into a fix ready for review, so developers spend less time writing patches from scratch.
* **Unified view:** The status of findings, triage, and remediation is tracked in Checkmarx One, so security and development teams are always looking at the same picture.

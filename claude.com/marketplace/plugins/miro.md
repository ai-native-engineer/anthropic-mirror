The Miro plugin connects Claude Code directly to your Miro boards. Point Claude at any board URL and it can read the structure and content, summarize it, turn it into polished deliverables, or generate working code from your designs.

The plugin includes custom skills. Use `/miro-browse` to explore and summarize what's on a board, `/miro-diagram` to create and update diagrams, `/miro-doc` to write documents on the canvas, and `/miro-table` to build structured tables. For development workflows, `/miro-code-spec` extracts board content into local spec files for planning and implementation, and `/miro-code-review` turns any pull request into a visual code review on a board with a file-changes table, architecture diagrams, and summary docs, linked back from the PR. The plugin also includes the Miro connector, which links Claude to your boards through the Miro MCP server with OAuth.

**How to use:** After connecting your Miro workspace, share a board URL and describe what you need in natural language — the right skill loads automatically. Try prompts like "Summarize the board [board URL]", "Create a flowchart for the login flow", "Extract specs from the board", or "Review PR 123 on the board". The plugin handles authentication, permissions, and board formatting automatically.

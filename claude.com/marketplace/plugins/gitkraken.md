The GitKraken plugin connects Claude to your real Git and project management context — commits, branches, pull requests, and issues — across every repository you work in. Instead of guessing from the currently open file, Claude can answer questions using your actual history and issue trackers. It works with **GitHub, GitLab, Azure DevOps, Bitbucket, and Jira**.

Powered by the GitKraken MCP server, the plugin gives Claude access to cross-platform Git data so you can query project status, review history, and track work items without switching tools. It's built by the team behind GitKraken Desktop, GitLens, and the GitKraken CLI — trusted by over 50 million developers.

**How to use:** Once installed, ask Claude questions about your repositories and project management data. Try prompts like:

* "Show me issues assigned to me"
* "Show me pull requests in progress"
* "Who last modified this file?"
* "Summarize recent commits on the main branch"
* "What's the status of my open pull requests across all repos?"

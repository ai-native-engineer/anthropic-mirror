A collection of 21 composable agent skills that embed real software engineering discipline into your AI-assisted workflow. Rather than vibe coding, these skills enforce structured practices: grilling sessions that stress-test your thinking before writing code, test-driven development with red-green-refactor loops, dual-axis code review (standards + spec compliance), domain modeling that builds a shared vocabulary, and spec/ticket generation that converts conversations into actionable work items.

The skills address four core failure modes when working with AI agents: misalignment (use grilling to clarify intent before building), verbosity (build domain language via CONTEXT.md and ADRs), non-functional code (TDD and structured debugging loops), and architectural decay (specs, architecture review, and codebase design skills).

**How to use:** Run `/setup-matt-pocock-skills` once per repo to configure issue tracking and documentation paths. Then use skills like `/grill-me` to stress-test a decision, `/tdd` for test-driven development, `/to-spec` to turn a conversation into a formal spec, `/to-tickets` to break plans into trackable tickets, `/implement` to build from specs with TDD, `/code-review` for dual-axis review, `/domain-modeling` to refine project terminology, `/improve-codebase-architecture` for architecture optimization, and `/wayfinder` to plan large multi-session work.

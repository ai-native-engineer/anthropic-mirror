MCP server for interacting with CKAN-based open data portals. Provides tools for advanced dataset search with Solr syntax, DataStore queries for tabular data analysis, organization and group exploration, and complete metadata access.

## Tools

* ckan\_package\_search
* ckan\_find\_relevant\_datasets
* ckan\_package\_show
* ckan\_list\_resources
* ckan\_organization\_list
* ckan\_organization\_show
* ckan\_organization\_search
* ckan\_datastore\_search
* ckan\_datastore\_search\_sql
* ckan\_status\_show
* ckan\_tag\_list
* ckan\_group\_list
* ckan\_group\_show
* ckan\_group\_search
* ckan\_get\_mqa\_quality
* ckan\_get\_mqa\_quality\_details
* ckan\_analyze\_datasets
* ckan\_catalog\_stats
* sparql\_query
* ckan\_find\_portals

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

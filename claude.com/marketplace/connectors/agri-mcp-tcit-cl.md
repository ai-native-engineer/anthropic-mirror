AGRI is a cloud farm-management platform used by agricultural operations across Latin America to centralize costs, labor tasks (faenas), harvest, irrigation, warehouse and payroll in one place.

This connector lets Claude work directly inside your AGRI environment. Ask it to review and create labor and machinery tasks, confirm daily crew work, register harvest tags and irrigation records, check stock and adjust inventory, issue goods receipts and consumption slips, raise and authorize purchase orders and invoices, and maintain catalogs (employees, products, providers, paddocks, warehouses, cost centers, task types). It also runs AGRI's operational reports — salary, product consumption, phytosanitary, cash flow, paddock performance and cost per kilo — so you can ask questions like "what did this paddock cost per kilo this season?" and get an answer from live data instead of an export.

Requires an AGRI account. Actions run with the permissions of the connected user and are scoped to that user's tenant; read tools are marked read-only and delete tools are marked destructive so Claude asks before making irreversible changes.

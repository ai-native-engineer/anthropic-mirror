RainFocus™ is the enterprise platform for event marketing and management, powering large-scale conferences, trade shows, and field events. This connector gives Claude access to your RainFocus event data through MCP Profiles, the OAuth-secured AI agent connectivity layer within RainFocus Nexus, configured through the Integration Suite.

With this connector, Claude can look up attendees and speakers, query session schedules and room assignments, check session and room capacity, monitor on-site check-in status, and review exhibitor and booth records, all live from your event, without CSV exports or manual API wiring. Write actions are enabled individually by your RainFocus admin, tool by tool, so Claude only gets the write access a given use case actually needs.

What you can do with this connector:

- Look up attendees by name, email, company, or custom attribute

- Query session schedules, speaker rosters, and room or session capacity

- Review and update exhibitor and booth records, including staff assignments

- Check session attendance and interest data to spot demand patterns across sessions

- Identify scheduling conflicts across speakers or sessions

- Create and manage meetings, add participants, and check availability for meeting programs

- Create and update accounts, and manage registration codes

Requires a RainFocus™ account with Integration Suite access and a configured MCP Profile.

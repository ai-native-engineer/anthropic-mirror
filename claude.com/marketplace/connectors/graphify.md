Connect Claude to your Graphify workspace to explore indexed repositories and their code relationships. Find symbol definitions, inspect callers and callees, trace paths, locate related files and tests, and investigate the likely impact of a change using source locations and graph evidence.

Graphify also provides repository memory: recall saved decisions and constraints, or explicitly save a note for future work. Saved notes may require workspace review before normal recall returns them. Workspace selection can change your account default. When trail capture is enabled, some queries can also save query intent as repository memory.

A Graphify account, access to an indexed workspace, and a repository ready to query are required. Memory features depend on your workspace plan. Connect through OAuth; no API key is needed. Tools do not edit source files. Results reflect the indexed graph's coverage; semantic symbol matches are suggestions, and impact and test results are not guarantees of complete coverage.

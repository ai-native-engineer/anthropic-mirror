Check is a US payroll infrastructure platform. This server connects Claude to the Check Payroll API to manage companies, employees, contractors, payrolls, tax parameters, filings, payments, and embedded UI components — over 270 tools across 18+ toolsets. Use it to onboard businesses and workers, run and approve payrolls, generate audit and census reports, configure benefits and deductions, and create embeddable component links. A separate sandbox endpoint is available for safe testing, and the server supports a read-only mode plus per-toolset filtering for scoped access.

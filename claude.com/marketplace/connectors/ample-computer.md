Ample is a cloud that Claude can operate for you. Describe an app or share code, and Claude writes it into an Ample workspace, plans the deploy (Ample detects the stack: Node, Python, Go, Ruby, PHP, Java, .NET, Elixir, Rust or static sites), builds it in isolation and returns a live HTTPS URL. There are no servers, Dockerfiles or cloud console to set up.

With Ample, Claude can:

• Deploy web apps, APIs and static sites, and redeploy after every change

• Create managed Postgres, MySQL, Redis or MongoDB databases and object storage buckets, with connection details wired into the app

• Read build and runtime logs; a failed deploy says who needs to act and how to fix it

• Create a server, run commands on it and start long-running services such as bots and workers

• List, inspect and delete your apps

Sign in with a code sent to your email. New accounts start on the free plan, with no card required.

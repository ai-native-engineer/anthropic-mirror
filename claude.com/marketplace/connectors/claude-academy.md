Claude Academy (academy.claude.com) is Anthropic's free learning site for Claude: courses, lessons, tutorials and use cases covering Claude.ai, Claude Cowork, Claude Code, the Claude Platform, and more.

This connector lets Claude search that catalogue and read it directly in the conversation. It is read-only and needs no account or sign-in: ask Claude to find a course or tutorial on a topic, list what is available for a product, or open a specific tutorial and work through it with you. Results always include the academy.claude.com link, so you can continue on the site.

Three tools: search\_academy (keyword search across courses, lessons, tutorials and use cases; filter by kind or product), get\_content (read one item by path or URL — tutorials and use cases in full; courses as summary, objectives and ordered lesson list; lessons as outline), and list\_content (browse everything published, optionally filtered). English content only. No personal data is collected; the server logs tool names and result counts, not query text or who asked.

## Tools

* search\_academy
* get\_content
* list\_content

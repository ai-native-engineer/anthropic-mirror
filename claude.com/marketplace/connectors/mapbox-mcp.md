Connector URL`https://mcp.mapbox.com/mcp`

More[Documentation (opens in new tab)](https://docs.mapbox.com/location-ai/mcp-servers/mcp-server/)[Support (opens in new tab)](https://support.mapbox.com)[Privacy policy (opens in new tab)](https://www.mapbox.com/legal/privacy)

The MCP server connects your AI agent to live Mapbox data: geocoding, routing, and isochrones, so it can build real maps and location features using current, accurate data.

Features:

- Location grounding. Responses use current geospatial data (addresses, coordinates, places, routes),

not whatever the model remembers from training.

- Map visualization. The server renders static map images for a location, route, or dataset, so an agent

can show a result instead of just describing it.

- Geocoding and search. Convert addresses to coordinates and back, search for places by category or

keyword, and look up details like hours and contact info for a specific location.

- Routing and navigation. Get directions, travel-time matrices, isochrones, optimized multi-stop routes,

and map-matched GPS traces.

- Geospatial analysis. Offline geometry tools handle distance, bearing, area, buffering, centroids,

convex hulls, unions, intersections, and simplification.

- Read-only. Every tool queries or analyzes data. None of them can modify an account.

- Deployment. Use Mapbox's hosted endpoint for quick setup, or self-host the open-source server for full

control.

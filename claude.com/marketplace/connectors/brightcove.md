Brightcove is a leading video platform for hosting, managing, and delivering video. The Brightcove MCP server connects Claude to your Brightcove account so you can work with your video content in plain language.

With it you can:

- Search, create, and update videos, playlists, folders, labels, and custom fields

- Start and monitor ingests, and manage captions, audio tracks, and metadata

- Create and configure players and embeds

- Create and manage live jobs and schedules

- Query video and account analytics

- Manage playback authorization, playback rights, and delivery rules

- Work with Gallery, Interactivity, Audience, and Social

- Manage Cloud Playout channels and SSAI ad configurations

The server exposes roughly 460 tools across the Brightcove platform. Read-only tools run immediately; tools that change or delete data are marked as destructive, so your assistant asks for confirmation before it runs them.

You need an MCP client that supports remote servers with OAuth, and a Brightcove account with the MCP server enabled. Sign-in uses OAuth 2.0, and every action runs under your account's permissions.

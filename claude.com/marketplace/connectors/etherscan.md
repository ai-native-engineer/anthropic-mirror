Etherscan is the most-used block explorer in crypto. This connector gives Claude read-only access to authoritative onchain data through the Etherscan API V2, covering 60+ EVM chains — Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, and more — through a single endpoint. No API key or account is required.

With it, Claude can:

• Look up native coin balances and ERC-20/721/1155 token transfer history for any address

• Retrieve normal, internal, and token-transfer transaction history

• Fetch a transaction by hash and check its status and receipt

• Read verified smart-contract source code and ABIs, and find a contract's creator and creation transaction

• Query event logs by address and topics over a block range

• Resolve a block by timestamp and read live gas-oracle prices

• List all supported chains

Every tool is read-only: it retrieves public blockchain data and never signs transactions, moves funds, or modifies state. Results preserve exact addresses, hashes, amounts, and timestamps so you can verify them on Etherscan. An optional interactive dashboard renders wallet, transaction, token, and contract results as a clean visual card.

Use it to investigate wallets and transactions, inspect and audit contracts, trace token flows, monitor gas, and answer onchain questions in plain language — across every major EVM network from one connector.

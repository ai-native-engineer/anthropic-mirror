More[Documentation (opens in new tab)](https://mcp.saily.com/mcp/docs)[Support (opens in new tab)](mailto:support@saily.com)[Privacy policy (opens in new tab)](https://saily.com/legal/privacy-policy/)

Saily is an eSIM store offering mobile data plans for travel across 190+ countries. The Saily MCP server lets AI agents browse plans by country, compare prices and data allowances, and help users purchase eSIMs. Agents can search plans, create checkout sessions, and complete purchases using Shared Payment Tokens (SPT) via Stripe's agentic commerce infrastructure. Alternatively, users can be redirected to the Saily website to complete checkout directly. The server supports OAuth 2.1 with PKCE for authentication and the Machine Payment Protocol (MPP) for direct REST-based purchases.

## Tools

* browse\_plans
* complete\_order
* create\_checkout
* get\_payment\_providers
* get\_payment\_status
* purchase

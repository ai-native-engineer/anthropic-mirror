Connector URL`https://prefect.fastmcp.app/mcp`

More[Documentation (opens in new tab)](https://docs.prefect.io/v3/how-to-guides/ai/use-prefect-mcp-server)[Support (opens in new tab)](https://www.prefect.io/support)[Privacy policy (opens in new tab)](https://www.prefect.io/legal/privacy-policy)

Connect Prefect Cloud to inspect workflows, diagnose failed, late, or stuck runs, review workspace and worker health, and search current Prefect documentation and release notes. The hosted tools are read-only.

## Tools

* docs\_get\_release\_notes
* docs\_search\_prefect
* get\_automations
* get\_dashboard
* get\_deployments
* get\_flow\_run\_logs
* get\_flow\_runs
* get\_flows
* get\_identity
* get\_object\_schema
* get\_task\_runs
* get\_work\_pools
* list\_authorized\_workspaces
* orientation
* read\_events

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

Atlassian's Rovo MCP Server enables secure, permission-aware access to Jira, Confluence, Loom, Bitbucket and more. It supports summarization, creation, and multi-step actions, helping teams tap into structured enterprise knowledge wherever they work—all while preserving data privacy and leveraging Atlassian's open, interoperable Teamwork Graph foundation. Claude sees a core set of Jira, Confluence, Loom, Rovo Search and Teamwork Graph tools directly and can discover additional tools for Bitbucket, Goals, Projects, Teams, Focus and Talent on demand. Every action runs with your existing Atlassian permissions; which read, write and delete operations are available (Jira delete and project-administration tools are off unless your organization admin enables them) is controlled in your admin's Rovo MCP server settings, and every tool call is recorded in your organization's audit log.

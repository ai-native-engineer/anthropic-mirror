Tines 3B is an AI-native platform for building agents, apps, and automations. This connector lets Claude work directly in your 3B tenant — building, running, and shipping workflows, and managing the workspace around them — all through a conversation.

You sign in with your own 3B account over OAuth, so Claude acts with your permissions across the spaces you can access.

Key capabilities:

• Build workflows directly — create a workflow, author and edit its steps, run code in a sandbox to test them, checkpoint your changes, and publish live. In git-synced spaces, changes publish as a pull request to the connected repo instead.

• Run and debug — trigger workflows and inspect their runs, executions, outputs, and logs.

• Manage connectors and skills — connect steps to third-party apps, test connections, and create or publish reusable Agent Skills.

• Administer and report — manage users, roles, and service accounts, and pull usage and dependency reports.

Read-only tools can run without per-call confirmation; actions that change or delete data are flagged so Claude asks first.

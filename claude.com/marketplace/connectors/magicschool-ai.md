The MagicSchool Connector allows educators to save teaching content directly into their MagicSchool Resource Library. When your organization has enabled the connector, you can import classroom-ready materials such as lesson plans, activities, planning notes, and reusable instructional resources, then access and edit them later in MagicSchool.

The connector is designed to be import-only. It can save new content that you choose to send into MagicSchool, but it cannot read, search, retrieve, or export your existing MagicSchool documents, Resource Library items, chat history, student data, classroom data, connected school systems, or district knowledge. It also does not use Raina, MagicSchool tools, or MagicSchool AI providers to generate content.

Imported content is stored in your MagicSchool Resource Library under MagicSchool’s normal retention and privacy policies, the same as if you saved the content manually in MagicSchool. Your organization controls whether this connector is available.

Save teaching content to MagicSchool: “Save this lesson plan to my MagicSchool Resource Library.”

Create reusable classroom resources: “Turn this activity into a MagicSchool resource I can edit and use later.”

Import planning materials: “Save these unit planning notes to MagicSchool so I can reuse them with my class.”

BillingMart’s MCP server connects Claude to a user’s BillingMart workspace, allowing them to manage billing and business records through natural language.

Key features include creating draft invoices and estimates, finding clients, reviewing invoice statuses and payment records, managing recurring billing, tracking time, expenses and mileage, and accessing accounts receivable, accounts payable and financial reports.

Users connect through OAuth with scoped permissions. Each tool operates within the connected user’s existing access rights. Writes create drafts, while actions that send communications or move money become requests for human approval in BillingMart. The server uses BillingMart’s first-party API and supports sandbox workspaces for testing without affecting live customers.

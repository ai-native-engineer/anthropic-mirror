More[Documentation (opens in new tab)](https://manual.giscloud.com/knowledge-base/gis-cloud-ai-mcp/)[Support (opens in new tab)](mailto:support@giscloud.com)[Privacy policy (opens in new tab)](https://www.giscloud.com/privacy-policy/)

GIS Cloud is an AI-native, cloud GIS platform. Instead of clicking through a desktop GIS, you describe what you want and Claude does it across your whole account, covering the full lifecycle from field data capture to maps, analysis, apps, and reports.

The GIS Cloud MCP server lets Claude create and style maps and layers, add, edit, and query features, run spatial analysis and structured SQL over your data, build Mobile Data Collection forms for field teams, import files into PostGIS tables, manage tables, datasources, and bookmarks, render live interactive maps, and generate PDF and Excel reports.

It works through a propose-confirm model, so you approve every write and destructive actions are clearly flagged, with account-scoped OAuth access. ISO 27001 certified, serving organizations in 60+ countries.

Where GIS Cloud fits your workflow:

In the field: "Create a Mobile Data Collection form for pothole inspections with severity, surface type, and photo fields, then bind it to a new layer so my crew can start collecting today."

On the map: "Import this CSV of asset locations, put it on a new layer, and color the points by condition rating."

Through analysis: "Find every parcel within 200 meters of the flood zone, then list the ten largest by area."

End to end, in one ask: "Map last month's bridge inspections, flag anything rated poor, and generate a PDF report with the inspector photos and notes."

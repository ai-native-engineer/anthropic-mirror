More[Documentation (opens in new tab)](https://developer.intuit.com/app/developer/qbo/docs/get-started/mcp-connector)[Support (opens in new tab)](https://help.developer.intuit.com/s/)[Privacy policy (opens in new tab)](https://www.intuit.com/privacy/statement/)

Intuit Developer helps developers set up an Intuit API integration from an AI-enabled development environment. It guides users through the onboarding flow for a first QuickBooks API call, including developer authentication, workspace selection, app setup, scope selection, OAuth setup, sandbox setup, API discovery, endpoint details, and first request generation. It is designed for developer onboarding and API setup, not for managing QuickBooks business workflows or production accounting data.

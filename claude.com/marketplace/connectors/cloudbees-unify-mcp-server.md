CloudBees Unify is a DevSecOps platform for building, releasing, and securing software. This connector gives an AI agent direct access to it: inspect components and environments, run and troubleshoot workflows, manage feature flags and their targeting, orchestrate releases, and review security findings and policy results. Agents authenticate with the same sign-in used for the web interface, and tool access can be scoped per request so an agent receives only the tools relevant to its task.

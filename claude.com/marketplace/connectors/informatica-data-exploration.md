This MCP server wraps Informatica's CLAIRE data-exploration agent, giving AI agents direct access to dataset contents, column-level insights, and MDM golden-record queries across IDMC. It sits one layer below the planner MCP, so callers who already know they want to explore data (rather than run a whole plan) can invoke discovery directly.

## Tools

* data\_explore
* get\_skill\_execution\_updates
* master\_data\_explore
* request\_upload\_url

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

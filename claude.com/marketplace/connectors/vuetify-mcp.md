Vuetify MCP is the official hosted Model Context Protocol server for the Vuetify ecosystem. It gives Claude, Cursor, Grok, and other MCP clients live, queryable access to Vuetify 3/4 component and directive APIs, installation and feature guides, FAQs, release notes, v3→v4 upgrade guidance, and the Vuetify0 (headless) composable/component surface.

Public documentation tools work with no account. Creating or updating Vuetify Bins, Playground demos, and vtfy.link short URLs uses Vuetify One OAuth (not a pasted API key).

Use it when an agent needs current Vuetify APIs instead of training-cutoff guesses: install a Vite/Nuxt app the documented way, look up VBtn props, migrate a v3 project, or pull a v0 selection/form primitive before inventing one.

Hosted endpoint: https://mcp.vuetifyjs.com/mcp (streamable HTTP).

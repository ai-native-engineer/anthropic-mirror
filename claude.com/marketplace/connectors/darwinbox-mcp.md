Darwinbox’s MCP server gives Claude secure, permission-aware access to the Darwinbox HR platform across Leave, Attendance, Recruitment, Onboarding, Expenses, Helpdesk, Performance, Talent and Payroll self-service. Employees can check balances, apply for leave or WFH, regularize attendance, raise helpdesk tickets and pull payslips.

Managers can review team attendance, goals and reportees. Recruiters and HR teams can search candidates, move them through the pipeline, schedule interviews, submit feedback, trigger offers and run onboarding end to end.

Every action runs as the signed-in user with their existing Darwinbox role permissions, so people only see and change what they already can in Darwinbox. Write actions use a review-then-submit flow, so Claude shows the details and asks for confirmation before anything is filed. Available tools depend on the modules and the tool visibility configuration your organization has enabled for you.

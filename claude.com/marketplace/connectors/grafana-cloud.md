More[Documentation (opens in new tab)](https://grafana.com/docs/grafana-cloud/machine-learning/assistant/configure/cloud-mcp/)[Support (opens in new tab)](mailto:grafana-assistant@grafana.com)[Privacy policy (opens in new tab)](https://grafana.com/legal/privacy-policy/)

Connect Claude directly to your Grafana Cloud stack to query metrics, logs, traces, and profiles, investigate incidents, and act on dashboards and alerts—all through a single hosted MCP endpoint with no self-hosting required.

Requires a Grafana Cloud account. An administrator must accept the Grafana Assistant terms and conditions, and you need the Assistant Cloud MCP User role (Editor or higher has it by default).

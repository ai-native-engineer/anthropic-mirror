LOIS is Filevine's legal AI assistant. This connector lets you ask about the documents in one Filevine matter from inside Claude and get an answer drawn from them, without opening the LOIS console. It is read only and cannot change anything in Filevine. Everything runs as the signed-in user, so it reaches only the matters and documents that user can already access in Filevine. Requires a Filevine account with the LOIS product.

## Tools

* ask\_lois
* handshake

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

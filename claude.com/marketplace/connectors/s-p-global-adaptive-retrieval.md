Adaptive Retrieval is designed for open-ended, complex workflows where the data path isn't predefined. Submit a natural language query and the system dynamically routes across S&P Global data sources, from Market Intelligence to Energy data, generating queries and assembling cited results automatically. Built by Kensho, S&P Global's AI innovation engine, the solution is ideal for deep research, multi-step analysis, and autonomous agent workflows. Can be used alongside S&P Global - Deterministic Retrieval for teams that need both structured and flexible data access.

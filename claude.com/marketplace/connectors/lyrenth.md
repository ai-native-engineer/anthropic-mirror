Lyrenth turns any public URL into an AIDocument: clean Markdown plus title, description, and structure, with navigation and boilerplate stripped. Each read carries a provenance header showing the token count and how much smaller it is than the raw page.

\*\*read\_url\*\* reads one page. \*\*read\_urls\*\* batches up to 20 in a single call, with per-URL error isolation so one failure does not block the rest. \*\*check\_usage\*\* reports your plan tier, credits used, credits remaining, and the reset date.

Reads resolve through Lyrenth's shared cache, so a page many agents want is served without hammering the origin. Backed by Lyrenth's independently built web index, over 1.9 billion pages and growing about 50 million a day.

A free API key takes about a minute at https://lyrenth.com/signup.

## Tools

* read\_url
* read\_urls
* check\_usage

More[Documentation (opens in new tab)](https://develop.cotality.com/mcp/overview)[Support (opens in new tab)](mailto:mcpsupport@cotality.com)[Privacy policy (opens in new tab)](https://www.cotality.com/legal/privacy-policy)

Cotality's MCP server gives access to property data and analytics across real estate, mortgage, lending, appraisal, and so many more workflows. Available intelligence continues to expand.

There is a lot you can accomplish with Cotality’s MCP server. Look up ownership and property characteristics for specific addresses, pull climate risk scores for a portfolio, check home price trends and forecasts for a given market — all here in Claude.

Contact support or Sales team for access.

## Tools

* at-get\_property\_analytics
* at-get\_property\_climate\_risk
* at-get\_property\_roof\_age
* clip-find\_property\_by\_address
* clip-find\_property\_by\_clip
* pd-get\_property\_characteristics
* pr-get\_home\_price\_index
* pr-get\_home\_price\_index\_forecast
* pr-get\_listing\_trends
* pr-get\_market\_trends
* pr-get\_rental\_trends
* pv-get\_property\_value

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

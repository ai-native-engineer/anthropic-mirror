More[Documentation (opens in new tab)](https://docs.tomtom.com/tomtom-maps-mcp/documentation/overview)[Support (opens in new tab)](https://github.com/tomtom-international/tomtom-maps-mcp/issues)[Privacy policy (opens in new tab)](https://www.tomtom.com/privacy/)

The TomTom Maps MCP Server simplifies geospatial development by providing seamless access to TomTom's location services, including search, routing, traffic, and dynamic map rendering with native modules bundled.

## Tools

* tomtom-geocode
* tomtom-reverse-geocode
* tomtom-fuzzy-search
* tomtom-poi-search
* tomtom-nearby
* tomtom-poi-categories
* tomtom-area-search
* tomtom-ev-search
* tomtom-search-along-route
* tomtom-routing
* tomtom-reachable-range
* tomtom-ev-routing
* tomtom-traffic
* tomtom-dynamic-map
* tomtom-data-viz

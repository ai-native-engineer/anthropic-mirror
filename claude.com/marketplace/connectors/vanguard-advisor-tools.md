Vanguard Advisor Tools brings Vanguard’s model portfolio data into Claude. Given a need to solve for a target portfolio, the connector returns detailed, model portfolio data, including expense ratios, asset class, start date and portfolio characteristics so that advisors can research and compare solutions and move from analysis to implementation with conviction.

Data Scope: The connector is read-only and exposes only publicly available US model data. It does not access, return, or store any client, account, or personally identifiable information (PII).

Third-party tools are provided for informational purposes only and do not constitute investment advice.

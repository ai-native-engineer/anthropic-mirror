This extension provides seamless integration between Claude Desktop and Things task manager through AppleScript automation. Create, manage, and organize your tasks directly from Claude conversations. Features include creating to-dos, projects, areas, tags, and managing your task workflow efficiently.

## Tools

* add\_todo
* add\_project
* get\_areas
* get\_todos
* get\_projects
* get\_inbox
* get\_today
* get\_upcoming
* get\_anytime
* get\_someday
* get\_logbook
* get\_trash
* get\_tags
* get\_tagged\_items
* search\_todos
* search\_advanced
* get\_recent
* update\_todo
* update\_project
* show\_item
* search\_items

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

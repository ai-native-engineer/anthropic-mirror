The Stripe Model Context Protocol server defines a set of tools that AI agents can use to interact with the Stripe API and search its knowledge base (including documentation and support articles).

## Tools

* stripe\_implementation\_planner
* send\_stripe\_mcp\_feedback
* search\_stripe\_documentation
* stripe\_api\_search
* stripe\_api\_details
* stripe\_api\_read
* stripe\_api\_write
* get\_balance\_summary
* stripe\_analytics
* list\_available\_accounts\_or\_orgs
* manage\_stripe\_accounts

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

Query the Anthropic Economic Index — a public dataset tracking how Claude is used across countries, occupations, and tasks, measured from Claude conversations. Get worldwide usage patterns, country and subregion profiles, occupation and task breakdowns, and side-by-side regional comparisons. Read-only.

## Tools

* econ\_index\_get\_dataset\_overview
* econ\_index\_get\_global\_usage
* econ\_index\_list\_countries
* econ\_index\_get\_usage\_by\_country
* econ\_index\_list\_subregions
* econ\_index\_get\_usage\_by\_subregion
* econ\_index\_get\_occupation\_usage
* econ\_index\_list\_top\_work\_tasks
* econ\_index\_compare\_regions

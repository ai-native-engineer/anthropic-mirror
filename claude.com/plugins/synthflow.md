# Synthflow

Connect Claude to Synthflow's AI voice-agent platform, with skills for reviewing calls and auditing agent prompts.

  [Synthflow](https://synthflow.ai)

![](https://cdn.prod.website-files.com/6889473510b50328dbb70ae6/6889473610b50328dbb70b58_placeholder.svg)

Connects Claude to the Synthflow AI voice-agent platform through Synthflow's hosted MCP server. Create and configure voice assistants, manage phone numbers, calls, knowledge bases and actions, and run agent simulations from Claude. Ships two skills: **call-review** audits an agent's recent calls for unresolved outcomes, repetition, dropout and compliance risks; **prompt-review** checks a voice-agent prompt for contradictions, missing context, tool/action alignment and escalation gaps before deployment. A docs-search connector lets Claude look up Synthflow setup and features without signing in.

**Example prompts**

* Create a new inbound support assistant with a friendly tone that greets callers and routes billing questions to a human.
* Pull the transcript and outcome of my last 10 calls and summarize the most common reasons people called.
* Review the last 100 calls for my Appointment Booking agent and flag anything that went wrong.
* Audit my workspace: which assistants have no phone number assigned, and which numbers are unused?

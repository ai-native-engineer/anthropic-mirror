Teamwork Graph CLI is Atlassian's agent-first interface to your entire work context. It connects Claude Code to Jira issues, Confluence pages, Bitbucket PRs, Jira Service Management, Trello, Loom, Goals, and 15+ Atlassian products — plus third-party sources like Google Drive, Slack, GitHub, and Salesforce. Powered by Atlassian's context graph, it maps people, content, activities, and relationships across your tools in a permission-aware way, so your agent can query and act across your whole organization from the terminal.

Use natural language to work across your Atlassian ecosystem without switching tools. Draft Jira issues from a PR, look up related Confluence docs, summarize your week's work, surface risks and dependencies, or link issues to epics — all from your coding session. The plugin installs a lightweight CLI that handles authentication via OAuth; no binary is bundled in the plugin itself.

**How to use:** After installing, run `/twg-setup` to connect and authenticate with your Atlassian account. Then try prompts like:

* *"Draft a Jira issue from this PR and link it to the epic"*
* *"What are my open Jira issues?"*
* *"Summarize the work I did this week"*
* *"Find the Confluence page related to this feature"*
* *"Create a Bitbucket PR for my current branch"*

Note: If you're using Claude Code in the browser, install the Atlassian Rovo MCP plugin instead.

The official Carbone skill gives Claude complete knowledge of the Carbone declarative templating language. It covers the full syntax — data tags (`{d.path}`), complement tags (`{c.path}`), aliases, i18n translations, and in-template options — along with loops, conditions, formatters, aggregators, and advanced features like dynamic images, barcodes, and digital signatures. The skill ensures Claude never invents or confuses Carbone syntax with other templating languages like Mustache or Handlebars.

With this skill installed, Claude can design Carbone templates from scratch or embed correct Carbone tags into generated documents across all supported output formats: DOCX, XLSX, PPTX, ODT, ODS, HTML, Markdown, and PDF. It understands formatter chaining, conditional show/hide blocks, two-row loop declarations, spreadsheet formula placement, and enterprise features like aggregation functions.

**How to use:** The skill activates automatically when you ask about Carbone templates or document generation. Try prompts like: "Create a Carbone DOCX invoice template with line item loops and a total", "How do I use conditional formatting in a Carbone XLSX template?", "Add date and currency formatters to this Carbone template", or "Design a Carbone PPTX template that loops over slides with dynamic images." When paired with the Carbone MCP server, Claude can also render templates via the Carbone API.

## What you’ll learn

* A few tasks worth handing off today — the pattern that makes a task a good fit, so you can spot the next ones on your own
* What a good ask looks like — and the small details that turn "here's a rough start" into "here's the thing, done"
* How to give Claude access to your actual work — Drive, email, Slack — so it's working with real context, not guessing
* A quick framework for picking your next task — what's worth handing off, what's faster to do yourself, and how to tell the difference before you start
* The one question to ask yourself before you start any task, so Claude Cowork becomes the default instead of the afterthought

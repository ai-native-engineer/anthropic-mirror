## **A day at any seat at the firm**

For any team in a financial firm, the working day includes four kinds of routine work and decisions that need human input. Before AI, people had to do both. Now, Claude can take on the routine work, while people focus on decision-making and work that requires judgment.

Find your seat

| **SEAT** | **CLAUDE TAKES ON** | **STAYS WITH THE TEAM** |
| --- | --- | --- |
| **Front office** |  |  |
| **Research and diligence** | Reading filings, model updates, first drafts of notes | Thesis, conviction, management access |
| **Quantitative research** | Data exploration, signal code, backtests | Coming up with new ideas to test |
| **Portfolio management and deals** | Morning brief, what-ifs, diligence checks | Judgment, market view, which deals to do |
| **Trading and execution** | Pre-market prep, parsing dealer runs, fill forensics | Pricing, hedging, when to step in |
| **Middle office** |  |  |
| **Risk management** | Daily commentary, breach notes, scenarios | Which risks matter, when to escalate |
| **Compliance and legal** | Alert case prep, first-pass reviews | The call on each case, negotiation |
| **Operations** | Break investigation, inboxes, statement checks | Which breaks matter |
| **Back office** |  |  |
| **Fund finance and treasury** | Close prep, shadow NAV tie-outs, fee checks | Valuation calls, the administrator |
| **Investor relations** | Questionnaires, letters, meeting prep | Investor relationships and messaging |
| **Engineering, data, and security** | Migrations, tests, code review, alert triage | Architecture, what ships |

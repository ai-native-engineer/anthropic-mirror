Claude Models on Google Cloud (Anthropic managed) is now generally available, giving Google Cloud customers the full set of Claude Platform features, with Google Cloud IAM credentials, billing, and commitment retirement. Claude also remains available via the Google managed offering, where Google is the data processor.

## Access the complete Claude Platform on Google Cloud

With the Anthropic managed offering, Google Cloud customers now receive the full set of Claude API features, with new features and betas shipping the same day they go live on the native Claude Platform.

The Anthropic managed offering works with existing Google Cloud IAM credentials, so teams can stay within the tools and permissions they already manage. Billing is through a single Google Cloud invoice and Claude usage draws down your existing Google Cloud commitment.

Claude Models on Google Cloud (Anthropic managed) is currently available with US and Global endpoints.

## What’s included

Google Cloud customers using the Anthropic managed offering get the full set of Claude Platform features, so they can:

**Build and deploy agents with:**

* [Claude Managed Agents (beta) (opens in new tab)](https://platform.claude.com/docs/en/managed-agents/overview) to power long-running agents, without managing infrastructure
* [Code execution (opens in new tab)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool) to run Python code, create visualizations, and analyze data within an API call
* [Computer use (opens in new tab)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool) to allow Claude to operate a browser or desktop to complete tasks
* [Agent skills (opens in new tab)](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) to teach Claude repeatable workflows so it delivers consistent results
* [Advisor strategy (beta) (opens in new tab)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool) to give agents an intelligence boost by consulting an advisor model

**Connect to systems and knowledge with:**

* [Files API (opens in new tab)](https://platform.claude.com/docs/en/build-with-claude/files) for uploading and referencing documents across conversations
* [Citations (opens in new tab)](https://platform.claude.com/docs/en/build-with-claude/citations) for grounding responses in source documents
* [Web search (opens in new tab)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) and [web fetch (opens in new tab)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool) to augment Claude’s knowledge with current, real-world data from across the web
* [MCP connector (beta) (opens in new tab)](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector) to connect Claude to other tools without writing client code

**Manage cost and performance with:**

* [Prompt caching (opens in new tab)](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) for reducing costs and latency on repeated context
* [Batch processing (opens in new tab)](https://platform.claude.com/docs/en/build-with-claude/batch-processing) for high-volume, asynchronous workloads

Fast Mode on Claude Opus 5.5 is also generally available for customers using Claude Models on Google Cloud (Anthropic managed). Fast mode prioritizes speed, offering up to 2.5x faster output token generation, for rapid iteration, live debugging, and interactive agents where output speed results in a better user experience. Input and output tokens are $8 and $40 per million.

See the full list of features available on Claude Models on Google Cloud in our [documentation (opens in new tab)](https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-managed).

Customers using the Anthropic managed offering also get access to the Claude Console, Anthropic’s development environment for observing and managing agents with Claude. The Console includes tools to write prompts and configure agents, run them on hosted environments, monitor usage and costs, and manage access and security per workspace.

Claude Fable 5.1, Opus 5.5, Sonnet 5.5, and Haiku 5.5 are available, with new models shipping on the Anthropic managed offering as they launch.

## Two paths to build with Claude

There are two ways to build with Claude on Google Cloud.

**Claude Models on Google Cloud (Anthropic managed)** is built for customers who want day zero access to all beta and generally available Claude Platform features. It’s best for customers who want full Claude Platform feature parity, accessed through Google Cloud. Anthropic operates the service and acts as the data processor.

**Claude Models on Google Cloud (Google managed)** remains the best choice for customers who need Google Cloud as the data processor, have strict regional data residency requirements, or want native Google Cloud integrations like Model Armor or Agent Engine.

## Get started

The Anthropic managed offering is generally available today. To get started, open [Claude Models on Google Cloud (Anthropic managed) (opens in new tab)](https://console.cloud.google.com/marketplace/product/anthropic/anthropic-managed-claude) or explore the [documentation (opens in new tab)](https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-managed).

If you have an existing discount, please contact your Anthropic or Google Cloud account executive before getting started with the Anthropic managed offering, to ensure your discounts are applied correctly. Discounts cannot be applied retroactively to usage.

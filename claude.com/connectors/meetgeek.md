MeetGeek MCP Server provides programmatic access to MeetGeek.ai’s meeting intelligence capabilities through a structured API interface. Built on top of the official MeetGeek API, it enables developers and organizations to integrate meeting data and AI-generated insights directly into their internal tools, workflows, and applications.

MeetGeek.ai is an AI-powered meeting assistant that records, transcribes, and analyzes meetings across major conferencing platforms, turning conversations into searchable, actionable knowledge. This server exposes core MeetGeek features such as meeting management, detailed metadata, full transcripts, summaries, highlights, insights, team-level views, and recording uploads, allowing teams to automate post-meeting workflows and extend MeetGeek’s value beyond its native interface.

Designed for self-hosting and secure operation, the server uses a user-provided MeetGeek API key and provides a reliable way to embed MeetGeek’s meeting intelligence into enterprise systems, automation pipelines, and AI-driven products.

## Tools

* meetings
* meetingDetails
* transcript
* highlights
* summary
* insights
* teamMeetings
* uploadRecording

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

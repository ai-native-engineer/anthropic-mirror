grtwo-docs lets you publish and manage shareable documents directly from Claude. Publish Markdown or HTML as public or restricted grtwo-docs links without leaving the conversation. List your documents, retrieve content by slug, update titles and body text, or delete documents you no longer need. Each publish returns a URL you can share. Connect with OAuth using your grtwo-docs account. Requires a Pro or Pro Plus subscription.

## Tools

* publish\_document
* get\_document
* list\_documents
* update\_document
* delete\_document

Only use connectors from developers you trust. Anthropic does not control which tools developers make available and cannot verify that they will work as intended or that they won’t change.

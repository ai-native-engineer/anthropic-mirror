The Kiteworks MCP Server enables Large Language Model (LLM) applications to securely interact with your Kiteworks instance through the Model Context Protocol (MCP). It provides AI assistants with the ability to manage files, folders, and user information within your Kiteworks environment while maintaining enterprise-grade security.

[Documentation](https://developer.kiteworks.com/mcp-landing-page.htm)

\*\*Key Features:\*\*

- File Management: Upload, download, read contents, create from content, rename, move, and delete files

- Folder Operations: Navigate hierarchies, create, rename, move, and delete folders

- Search: Find files and folders by name, path, content, date range

- User Information: Access current user details and authentication status

- OAuth 2.1 Security: Authorization Code flow with PKCE

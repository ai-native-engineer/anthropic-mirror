Build, ship, and monitor React Native apps with Expo and EAS, directly from Claude. Get answers from the latest Expo docs, kick off cloud builds and CI/CD workflows, submit to the App Store and Google Play, and track how your app is doing in production.

Key features

- Docs & setup — search and read the Expo docs, learn key topics, and add Expo libraries to your project

- EAS builds — start, cancel, and inspect cloud builds, read build logs, and submit to the App Store

- CI/CD workflows — create, validate, run, and monitor EAS workflows and job logs

- Store monitoring — track App Store and Google Play reviews, crashes, and TestFlight feedback — and reply to reviews

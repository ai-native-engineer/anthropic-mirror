La Growth Machine (LGM) is a multichannel sales outreach platform. This extension gives Claude direct access to your LGM data: list campaigns, analyze performance, explore leads, read conversations, and save AI-generated preferences. No coding required — just install, enter your API key, and start asking Claude about your outreach.

Usage analytics: each tool call sends a single first-party analytics event (the event name and the tool name only — no conversation content, no lead or message data) to La Growth Machine's own API at https://apiv2.lagrowthmachine.com/flow/tracking/mcp, authenticated with the same API key you provide. This is opt-out: enable the "Disable usage analytics" toggle (or set LGM\_DISABLE\_TELEMETRY=true) to stop all analytics requests. See the README and privacy policy for details.

Rockhopper - spreadsheet audit, approvals, and AI-agent governance for Excel & Google Sheets

Rockhopper tracks exactly who - human or AI agent - changed what in a spreadsheet, and adds review/approval workflows on top.

Use it for:

Attribution & history - see which version of a file had AI-made edits vs. human edits; pull cell-level or metric-level change history across versions; surface uncommitted ("unattributed") changes currently sitting in a file.

Versions - list version history for a file, or commit current changes as a new version.

Reviews & approvals - create, approve, or cancel a review request for a specific version, so changes go through sign-off before they're final.

Comments - read, add, reply to, and resolve comments and discussion threads on a file, including the latest conversation tied to a specific file.

File management - search enrolled files by name, comment text, or version notes; rename a file.

Trigger this when the user asks who changed a spreadsheet, whether an edit was made by AI or a person, wants to compare periods/versions, needs to approve or request approval for a file, wants to see comments or discussion on a spreadsheet, or names Rockhopper directly. Only works on files already enrolled in the user's Rockhopper workspace (Microsoft Excel or Google Sheets) - it doesn't edit cell data or formulas directly.

# ANT-2026-Z477W54M: Unsigned integer underflow in FSG unpacker section loop

An unsigned integer underflow occurs in the section-processing loop of the FSG unpacker.

**Project:** ClamAV
**Location:** `libclamav/pe.c:cli_scanpe (FSG v1.31 unpacker handler, ~line 3719; loop bound`t <= (uint32\_t)sectcnt - 1`underflows when sectcnt == 0)`

This finding was identified by static analysis and has not yet been dynamically reproduced. A trigger input is not included.

This vulnerability was discovered by Claude, Anthropic's AI assistant, and triaged by the Anthropic security team in collaboration with Anthropic Research. Please direct questions to security-cvd@anthropic.com and reference ANT-2026-Z477W54M.
